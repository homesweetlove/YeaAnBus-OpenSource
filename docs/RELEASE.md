# 배포용 APK

> **공개 소스 저장소에는 APK를 포함하지 않습니다.** 개인 API 키, 네이버 지도 인증정보, 배포 서명키를 넣은 빌드는 공개하지 마세요. API 키 없는 CI 디버그 빌드는 기능 전체를 보증하지 않으며, 사용자 배포는 실기기 검증 후 별도로 진행합니다.

배포 빌드는 디버깅을 비활성화하고 R8을 적용하며, `.signing/release.properties`가 있으면 고정 배포 키로 서명합니다. `assembleRelease` 결과는 `app/build/outputs/apk/release/app-release.apk`입니다.

`.signing/` 폴더의 키와 비밀번호 파일은 Git 제외 대상입니다. 두 파일을 함께 안전하게 별도 백업해야 다음 버전도 동일한 서명으로 배포할 수 있습니다. 이 폴더는 APK와 함께 전달하거나 공개 저장소에 올리지 마세요. 개발용 서명과 배포용 서명은 서로 다릅니다.

기존 개발용 앱에서 배포용 앱으로 전환하려면 기존 앱 삭제 후 설치가 필요합니다. 삭제하면 즐겨찾기·설정·위젯을 다시 등록해야 합니다. 앞으로는 같은 배포 키를 유지하고 versionCode를 올려 업데이트합니다.

자체 배포 서명은 Google 인증이나 Play Protect 통과를 뜻하지 않습니다. 직접 설치 APK의 출처·스캔 경고는 남을 수 있습니다. Google Play 배포는 별도 개발자 계정과 심사가 필요하며 이번 작업에서 게시하지 않습니다.

사용자 요청에 따라 최종 화면·실기기 검증을 수행하지 않습니다. 설치 파일 생성에 필요한 서명 검증만 수행합니다.
