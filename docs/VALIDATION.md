# 검증 기록

> **공개본 안내:** 이 문서는 과거 개발 환경의 검증 이력을 기록합니다. 당시 스크린샷은 현재 앱 화면과 달라 공개 저장소에서 제외했습니다. 최신 Android 기기 UI/지도/예천 실서버 동작은 별도 검증이 필요합니다.

- 홈·검색·정류장·도착 카드 스타일을 정리하고 사용자 탭을 추가했습니다.
- 오션 블루·포레스트·라벤더·선셋 오렌지, 기기 설정/밝게/어둡게, 글자 크기 3단계를 지원합니다. 선택은 SharedPreferences에 저장됩니다.
- 데이터 절약(자동 조회 최소 30초), 지도 화면 켜짐 유지, 사용자 탭 즐겨찾기 관리를 추가했습니다.
- `assembleDebug`, `assembleDebugAndroidTest`, `lintDebug` 성공. 단위 테스트 39개 통과(실패·오류 0개).
- `ThemeSettingsTest` 1개 통과: 사용자 탭 이동, 포레스트·다크 선택, Activity 재생성 후 설정 유지, 밝은 테마 변경, 홈 복귀를 확인했습니다. 실행 기록은 `theme-ui-test.log`에 있습니다.
- 첨부 Oasis Focus 및 Appllama 디자인 스킬을 검토했습니다. 기존 Kotlin/Compose 구조를 유지하며 Material 컨트롤, 의미별 테마 색상, 스크롤 가능한 설정, 큰 글자 선택 영역의 줄바꿈을 적용했습니다. Appllama MCP는 연결되어 있지 않아 외부 앱 참고 화면 연구는 수행하지 않았습니다.
- 실제 휴대폰에서의 지도 종료 문제 재검증과 큰 글자·오프라인 등 전체 상태의 시각 검증은 남아 있습니다. 아래 이전 검증 기록은 당시 결과입니다.
- 테스트 캡처 회수를 위해 에뮬레이터를 다시 시작했으나 55초 내 준비되지 않아 종료했습니다. 이번 화면의 캡처 시각 검토는 완료하지 못했으며, 이전 스크린샷을 새 화면의 결과로 사용하지 않았습니다.

## 자동 테스트 범위

- GPS 이상값·중복 시각·시간 경과에 따른 위치 추정 및 보정
- 도로 투영, 도착 시간, 거리·속도에 따른 갱신 간격
- TAGO 단일/배열/빈 응답, 키 인코딩, BIS 한국 시각 해석
- 출발 예정 시각을 도착 시간으로 잘못 해석하지 않는 회귀 테스트
- BIS 오류 시 TAGO 대체 조회, 캐시, 즐겨찾기, 취소 전파
- BIS 정류장 목록의 중복 ID 제거
- 안동·예천 통합 검색에서 같은 ID/노선 번호 보존, 정확히 일치하는 검색 결과 우선 정렬
- 지역 경계와 무관한 주변 정류장 거리순 정렬, 일부/전체 조회 실패 안내, 검색 취소 전파

## 화면 및 실서버 확인

통합 검색 변경 전 Android 17 프리뷰 에뮬레이터에서 홈 → 검색, 실제 BIS 안동역 검색 → 도착 → 즐겨찾기 → 지도 → 홈 흐름을 확인했습니다.
최종 재실행에서 2개 테스트 모두 통과했으며 Gradle이 `BUILD SUCCESSFUL`로 종료했습니다.
최종 캡처에서 OpenStreetMap 배경 타일, 안동역 정류장 및 버스 마커 표시도 확인했습니다.
실제 화면은 `screenshots/01-home.png`부터 `screenshots/06-home-favorite.png`까지 저장했습니다.
이 캡처는 지역 선택 버튼 제거 전의 기록입니다. 이번 통합 검색 변경은 단위 테스트와 빌드로 검증하며, 화면 테스트 소스의 지역 선택 제거 확인도 컴파일합니다. 에뮬레이터 테스트는 이번 변경에서 다시 실행하지 않았습니다.

테스트 결과는 `app/build/reports/tests/testDebugUnitTest/index.html`,
`app/build/reports/androidTests/connected/debug/index.html`,
`app/build/reports/lint-results-debug.html`에서 확인할 수 있습니다.

## 확인이 남은 범위

- **TAGO 실서버 인증:** 사용자 키가 없어 MockWebServer로 검증했습니다. 키 입력 후 예천 조회와 실제 TAGO 대체 조회를 확인해야 합니다.
- **실제 버스 이동·ETA 정확도:** 예측 로직은 자동 테스트를 통과했으나 현장 이동 기록으로 오차를 측정하거나 계수를 보정하지 않았습니다.
- **알림:** WorkManager 조건 확인 구조만 구현되어 있으며 사용자 알림 게시는 후속 기능입니다.
- **릴리스 배포:** 생성된 릴리스 APK는 서명 전 파일입니다. 기기 설치에는 디버그 APK를 사용하거나 Android Studio에서 본인 키로 릴리스를 서명하세요.

프리뷰 에뮬레이터의 메모리 부족으로 System UI ANR와 간헐적인 PixelCopy 캡처 지연이 발생했습니다.
스크린샷은 기능 검증과 별도로 취급하며 시스템 오류 대화상자가 포함된 이미지는 앱 미리보기로 사용하지 않습니다.
초기 실행에는 지도 타일 DNS 오류도 있었으나 최종 실행에서는 정상 표시됐습니다.

## 2026-09-09 네이버 지도 전환

- osmdroid/OpenStreetMap을 네이버 지도 Android SDK 3.23.3으로 교체했습니다.
- 신규 Maps의 NCP_KEY_ID 인증을 사용하며 Client ID는 Git 제외 local.properties에서 읽습니다.
- 실제 지도 진입 테스트에서 버스 마커를 좌표 설정 전에 부착하면 InvalidCoordinateException(NaN)이 발생하는 문제를 재현했습니다.
- 마커 부착 전 좌표를 설정하고, 유효하지 않은 예측 좌표는 실제 GPS로 대체하도록 수정했습니다.
- TAGO 정류소·노선·도착·위치 서비스 모두 기존 키로 정상 인증(00)을 확인했습니다. 예천 터미널 정류장 검색은 6건을 반환했습니다.
- 네이버 지도 과금 한도는 사용자 콘솔 설정이며 앱 코드에서 강제하는 한도가 아닙니다.

- 수정 후 assembleDebug, testDebugUnitTest(37개), lintDebug 통과. 에뮬레이터 재검증은 LOW_MEMORY 종료 및 후속 실행 지연으로 완료하지 못했습니다. 실제 휴대폰에서 수정 APK의 지도 진입 확인이 남아 있습니다.
